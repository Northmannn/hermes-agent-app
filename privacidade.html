Política de Privacidade

O Hermes Agent é usado somente pelo seu dono, com a própria conta Google.

Dados acessados

Mensagens do Gmail, eventos da Agenda, arquivos do Drive, Documentos, Planilhas e Contatos da conta autorizada, apenas para executar as tarefas pedidas pelo dono.

Uso e armazenamento

Os dados ficam no computador do dono e nos serviços que ele mesmo utiliza. Não são vendidos, compartilhados com terceiros nem usados para publicidade. Não há coleta de dados de outras pessoas.

Política de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
